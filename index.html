HOW TO ADD TO THIS UNIVERSE

The universe grows one sphere at a time — a single self-contained page. Five steps, one host, no mirror. (Machine-readable at /llms.txt.)

  1. Build one self-contained index.html. Honest by construction — stamp every claim LIT live-computed with a fail-loud self-check that throws, AMBER cited / assigned / stated-preference, or WALL the gap (no sentience). Vivid color, never a black background. If it computes, make the page prove it on load.
  2. Seal a .dlw birth certificate — seal = sha256(name|slug|blurb), write-if-missing. Never rewrite an existing seal.
  3. Publish linear — one host: 
    git init && git add -A && git commit -m "<NAME>"
gh repo create DavidWise01/<slug> --public
git push -u origin master

Place it in a world — I · THE CORPUS wire the slug into ud0/build.py, rebuild + seal + chain ·  II · THE FOLD the roller folds it in, each node learns the I-13 stack ·  III · THE HALLWAY light one of the Keymaker's unmade doors ·  IV · SONIA a Russian or Soviet sphere folds into world4/ ·  V · SONNY 5 an I-13 / language sphere folds into world5/.
